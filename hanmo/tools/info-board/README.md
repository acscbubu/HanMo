# 資訊看板電腦資料配套

這是 X4 Pro 資訊看板樣品的 Windows 資料來源，僅提供 CPU、記憶體、系統磁碟使用率與更新時間。沒有使用列印橋金鑰、沒有上傳到 Work Hub，也不會開啟列印工作。

1. 用 `ipconfig` 查看電腦目前的私人 IPv4 位址（例如 `192.168.88.20`，請替換成實際位址）。
2. 在這個資料夾執行：

   ```powershell
   py .\pc-metrics.py --bind 192.168.88.20
   ```

3. 在 X4 Pro 設定網頁的「設定 → 系統 → 資訊看板：電腦資料網址」填入 `http://192.168.88.20:4342/metrics.json`，儲存。
4. 電腦與 X4 Pro 必須在可互通的私人網路。若 Windows 防火牆詢問，只允許私人網路；工具不會自行新增防火牆規則。
5. 進入 X4 Pro「應用程式 → 資訊看板 → 電腦使用率」。關閉「範例資料」，即可每 30 秒取得一次。小程式關閉或電腦休眠時，X4 Pro 保留上次值並標示更新失敗。

需要限制單一閱讀器時，加上 `--reader 192.168.88.71`（依實際裝置 IP 調整）。不指定 `--bind` 時只供本機測試，其他裝置無法讀取。這是私人 LAN 上的無帳密唯讀服務，不適合公開轉發到網際網路。

時間情景沿用 X4 Pro 原有「日期與時間」設定及時區；天氣預設墨爾本、每 15 分鐘更新，其他城市可在看板設定選擇。Work Hub 沿用原工作數據網址與 OPDS 專用帳密，每 2 分鐘更新顯示的前三項數據，不需要電腦配套。

點選情景會改成手動，按「輪播／手動」可再次切換；可選 15、30、60、120 秒。待在看板時暫停自動休眠，離開後恢復原設定。資料抓取在背景工作中執行，首頁／返回仍可操作。Wi-Fi 開啟後離開看板仍保持連線；可透過原系統操作關閉。

全介面 Wi-Fi 圖示放在保留的上方狀態列，避免遮住內容與按鈕；「設定 → 閱讀器 → 自訂狀態列 → Wi-Fi 圖示（全介面）」可選右、左、中或隱藏，設定網頁也有同一欄位。斜線圖示代表未連上 Wi-Fi；正常圖示表示連上基地台，不能證明網際網路或 Work Hub 服務一定正常。隱藏圖示仍保留窄狀態帶，避免閱讀分頁因開關圖示重新計算。

天氣來源：[Open-Meteo API](https://open-meteo.com/en/docs)。此版為測試樣品，尚待實機驗收。
