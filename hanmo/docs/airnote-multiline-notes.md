# AirNote 純文字筆記：多行建立與再編輯（候選）

- 在 AirNote「新增筆記」選「純文字筆記」，先輸入標題／檔名；確認後**直接進入多行文字鍵盤**，而非只能輸入「第一行」。鍵盤的「換行」與「儲存」是兩個不同的操作。儲存後才建立 `/AirNote/<標題>.txt`；此時取消不產生空檔案，空白／無效內容不能儲存。
- 從 AirNote 列表點既有的普通 `.txt` 筆記，直接帶入全文多行編輯；返回鍵放棄該次改動，儲存則保留原標題、換行與既有 `title\n\nbody\n` 檔案格式。清單類型仍進入原本的待辦清單畫面，其他檔案維持原本閱讀路徑。
- 每份筆記本文上限 16 KiB（**位元組**，不是字數），與既有 AirNote 網頁編輯上限一致。已儲存的中文 UTF-8 內容可以帶入、保留及再編輯；裝置鍵盤沒有中文輸入法，仍須用既有裝置網頁輸入中文字。
- 重新儲存前會檢查打開時的原始內容；若 SD 卡或網頁已修改檔案，不覆蓋對方變更。以 `.part` 和 `.bak` 暫存／復原機制提交；寫入失敗時舊檔保留，未儲存文字會重新帶回鍵盤供使用者處理。發生衝突時不要反覆強制儲存，請先取消並重新開啟或在網頁確認差異。
- 原本待辦清單的「新增第一個項目」仍是一行的單項輸入，不受純文字筆記多行模式影響。
